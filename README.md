little customized inte driver (based on 20.40.5171 / 15.40.5171)

📌 Project Overview

This distribution represents the low-level optimization and kernel-space injection of the graphics driver for Intel Haswell (HD Graphics 4600 / Gen 7.5) architectures. It is specifically engineered as a native multimedia component tailored for Windows 11 and MixOS operating systems. The core purpose of this compilation is to bypass the legacy hardware deprecation constraints imposed by the upstream OEM, enabling a high-efficiency hardware deployment within the modern Windows 11 and MixOS environments while maintaining absolute system stability.

🛠️ Architectural Enhancements & Changelog

The directive configuration file (igdlh64.inf) and the cryptographic signature database have been restructured to integrate the following optimizations directly into the display driver framework (WDDM 2.0):

- MPO Bypass (Multi-Plane Overlay): Enforces the injection of OverlayCaps and DisableMPO cryptographic keys into the graphics bus registry. This decouples the Windows 11 / MixOS desktop window manager (DWM) composition from hardware-accelerated video decoding loops (NV12/P010), effectively eliminating micro-stuttering.
- TDR Mitigation Layer (Timeout Detection & Recovery): Dynamically scales the critical hardware timeout threshold via an adaptive TdrDelay extension to 8000ms. This prevents abrupt 3D application crashes during heavy shader serialization routines, mitigating unexpected closures in modern rendering engines.
- Command Buffer Scaling: Optimizes the hardware ring buffer size (CommandBufferSize) to 0x1000. This accelerates dispatch timings and streamlines dynamic shared memory allocation (System VRAM) synchronization between the host CPU and the integrated GPU.
- Local Code-Signing Authentication: Generates a dedicated cryptographic catalog (igdlh.cat) hashed via SHA-256 using the official MixOS Dev. developmental digital certificate [image_AhH-g5.png]. This allows the host operating system to natively load the modified driver while keeping Secure Boot (UEFI) fully enabled within the motherboard firmware.

💾 Deployment & Provisioning Guide

Since this graphics driver utilizes a custom cryptographic chain generated by the MixOS development environment, the host operating system requires the pre-provisioning of the trust anchor before performing the hot hardware migration
Step 1: Establish the Trust Anchor.

1. Execute the root certificate Certificado_MixOS.cer with elevated administrative privileges
2. Initiate the Certificate Import Wizard and target the Local Machine storage scope.
3. Place the certificate strictly within the physical store path: Trusted Root Certification Authorities.

Step 2: Driver Subsystem Execution
- Option A (Automated): Execute the master installer binary igxpin.exe as an Administrator. The Intel setup deployment engine will automatically parse the modified .inf directives once the local signature validation passes.

- Option B (Manual): Open the Windows Device Manager, right-click the display adapter, select Update Driver, and target the root of the Graphics subfolder manually.

Step 3: Kernel Consolidation

Perform a complete system restart (Cold Boot) to force the Windows 11 / MixOS kernel to map the newly injected registry keys and purge legacy memory allocations from the display pipelines.
